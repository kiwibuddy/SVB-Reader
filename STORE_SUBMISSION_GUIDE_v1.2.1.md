## 8. Build and Submit Android

### Verify All Version Numbers:
```bash
# Check versions
grep "versionCode" android/app/build.gradle
grep "versionName" android/app/build.gradle
grep "version" app.json
```

**Should show:**
- versionCode: 20
- versionName: "1.2.1"
- app.json version: "1.2.1"

### Build Command:
```bash
# Build Android App Bundle (.aab)
eas build --platform android --profile production
```

### Submit Command:
```bash
# Submit to Google Play (internal track)
eas submit --platform android --profile production-android
```

**OR submit manually:**
1. Download .aab file from EAS
2. Go to Google Play Console
3. Navigate to Production → Create new release
4. Upload .aab file
5. Add release notes
6. Submit for review
